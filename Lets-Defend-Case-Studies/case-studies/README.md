# LetsDefend Case Studies — Phishing Incident Investigation

## Overview
Investigated a high-severity simulated phishing attack on the LetsDefend SOC platform, from initial alert triage through containment.

## What I Did
- Investigated a phishing attack involving a malicious email attachment
- Validated the suspicious file hash against 30+ threat intelligence sources
- Executed incident response actions: endpoint isolation, credential reset, IOC blocking
- Mapped the attack chain to MITRE ATT&CK techniques: T1566.001 (Spearphishing Attachment), T1204.002 (User Execution), T1071 (Application Layer Protocol)

## Skills Applied
Incident triage · Threat intelligence validation · MITRE ATT&CK mapping · Endpoint containment procedures
